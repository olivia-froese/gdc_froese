# Website Build Brief 

 

## 1. Project Overview 

 

Create a single-page website based on the approved Figma design. 

 

## 2. Design Reference 

 

Use the designated Figma frame as the primary visual reference.  

 

Inspect the design using the available MCP tools before implementation. 

 

## 3. Page Structure 

 

Identify the sections in the Figma design, in order 

 

List each section, document: 

 

- Purpose 

- Content 

- Layout 

- Typography 

- Colours and backgroun 

- Assets 

- Important spacing and alignment 

- Its relationship to adjacent sections 

 

## 4. Design System 

 

Document the colours, typography, spacing, content widths, buttons, and reusable components. 

 

- Colour palette 

- Typography 

- Spacing 

- Content widths 

- Grid and alignemnt 

- Buttons and other interface components 

 

## 5. Technical Requirements 

 

Build a complete, signle-page website using semantics, HTML5, CDD, and Javascript only where nedded. 

 

## 6. Responsive Behaviour 

 

Adapt the layout for desktop, tablet, and mobile. Preserve content hierarchy and usability. 

 

## 7. Acceptence Criteria 

 

The site must: 

 

- Include every required design section 

- Use the correct available assets. 

- Match the design's visual hierarchy 

- Work at different viewport widths 

- Have no broken local asset references 

- Be reviewed in a browser before completetion 

 

## 8. Outstanding Questions 

 

Record missing information or decisions that must be resolved before final approval.
