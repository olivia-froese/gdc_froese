# Project Instructions 

 

## Project Purpose 

 

Build a new, responsive, single-page website based on a supplied figma design. 

 

The website must reflect the intended visual hierarchy, layout, typography, colour palette, and content structure of the design. 

 

## Before Development 

 

- Read BUILD.md before implemeneting the website. 

- Inspect the designated Figma design using the available MCP tools. 

- Identify the required page sections and assets. 

- Review the design information before writing code. 

- Identify missing information before making significant assumptions. 

 

## Development Standards 

 

- Use semantic HTML5. 

- Use maintainable CSS. 

- Use Javascript only when required. 

- Use Flexbox and Grid where appropriate. 

- Reuse design assets when available. 

- Avoid unnecessary frameworks and dependencies. 

- Follow accessible web development practices. 

 

## Responsive Design 

 

- Support desktop, tablet, and mobile layouts. 

- Preserve the content hierarchy at smaller widths. 

- Prevent horizontal overflow. 

- Ensure text and interactive elements remain useable. 

 

## Quality Control 

 

- Compare the finished website with the Figma design. 

- Check image paths and style sheet references. 

- Inspect the website at different viewport widths. 

- Report unverified details honestly.
